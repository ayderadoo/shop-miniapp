Полный проект RAMP, версия 4.

Распакуйте архив. Для обновления GitHub загрузите содержимое архива в корень существующего репозитория с заменой одноимённых файлов.
Важно загрузить папки assets и img вместе с index.html и admin.html. Не загружайте сам ZIP вместо распакованных файлов.
Старые файлы репозитория удалять не требуется.
После загрузки дождитесь успешной сборки Vercel (Ready), полностью закройте мини-приложение Telegram и откройте снова.

Секретные ключи и токены ботов не входят в архив. Существующие настройки сервера сохраняются отдельно.
README.md содержит описание проекта. scripts/build_mobile.py создаёт два автономных HTML-файла для отдельной загрузки без папок ресурсов.
